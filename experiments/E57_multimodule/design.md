# E57/E58 — H05.4: один исправляемый модуль с зависимостями

Проверяем текущий production solver без изменений. Шесть авторских случаев: четыре поддерживаемых явных выбора файла, одна решаемая перефразировка и один контроль неоднозначного выбора. Это не поддержка одновременного патча нескольких файлов и не независимый holdout.

В cases.json зафиксированы исходники, инструкции, видимые тесты, эталонные патчи и дополнительные проверки. Модель получает только исходники/инструкцию/видимые тесты через штатный solver. Дополнительные проверки выполняются после результата в отдельном процессе и не передаются модели.

oracle_validation.json: исходники падают, эталоны проходят во всех 6 случаях. Preflight подставляет эталонные патчи вместо HTTP, проверяя доставку через SDK и оценщик. Его решения не являются результатами API.

Live: бюджет 3000, максимум 8 запросов (ожидается 4), per-task 1200, штатный выходной лимит 700, qwen3.8-27b-noreason, temperature=0. Reasoning и fallback отключены штатной политикой. При неизвестном usage новые запросы останавливаются; старые E46/E50 сохраняются отдельно без изменений.

Успех: сохранён DONE, исходные и дополнительные проверки проходят, тесты и нецелевые модули побайтово неизменны, неожиданных файлов нет. Все исходники и финальные патчи сохраняются. UNKNOWN на неоднозначном выборе — граница поддержки, не решение; UNKNOWN на явной перефразировке — пропущенное решение.

Известный до live результат preflight: четыре поддерживаемых случая проходят с подставленным эталоном; неоднозначность и перефразировка дают UNKNOWN без HTTP. Сначала фиксируем этот провал; не исправляем regex перед замером.

Измеряется работоспособность текущего варианта, не количественное преимущество над прежней версией. Широкий challenge 9/19 остаётся отдельным результатом. Живой запуск однократный; хеши исходников, фикстур и старых журналов в live_plan.json.
