# H04.12 / E71–E72: bounded full-text paraphrase expansion

Compare unchanged E70 scope gate (old) to an experimental v2 gate (new) adding two precise fullmatch patterns: a shared string key with one equality filter, or explicitly qualified distinct string keys with one equality filter. Both patterns specify all-pairs multiplicity and sum. Original grammar remains accepted. Referenced files/columns are checked. Additional clauses or unknown wording route to Python. No local parsed plan is substituted for the live model answer; JSON/Python prompts, models and executors remain unchanged. H04.13 (direct local execution of parsed specification) is NOT tested here.

Seven paired cases: exact known E70 paraphrase failure; new reversed filter/aggregate sides and repeated keys; new qualified keys with leading zeroes and repeated rows; original left grammar with changed values; negative scope controls with OR and an additional numeric condition; one representable phrase intentionally outside both grammars. Three cases change Python to JSON; four retain their old route. Cases are authored to the grammar, not a blind independent generalization set. No claims about arbitrary English.

Acceptance on this pilot: the three changed-route cases are all solved by the new version; no new wrong submissions relative to the paired old version; report overall correctness and cost, including controls. Keep every failure, even if improved elsewhere. Both arms make at most one API call per task. Alternate pair order, temperature=0, model qwen3.6-35b-a3b-noreason, output cap 400. Budget 4000 effective tokens, max 14 calls, per-task cap 800. Stop on unknown cost or remote exhaustion, no retries.

All seven numeric oracles are independently calculated by SQLite with TEXT keys. Expected routes/gold plans are not sent to the model. Validate parsed specifications separately. Preflight uses synthetic gold answers only to check SDK, routing, file preservation, and accounting. It is not evidence of model quality. Freeze before API. Preserve E46/E50 unknown-cost ledgers unchanged; main dispatcher stays unchanged.
