# E59/E60 — H05.5: распознавание цели ремонта

До API фиксируем четыре пары с идентичными входами для старого и нового solver. Использованы известные исходники E57, изменены только инструкции для трёх случаев: The bug is in, Only modify, Target file. Четвёртый — поддерживаемая прежде инструкция Update. Это механистическое сравнение, не новый независимый holdout.

Прежний solver сохранён без изменений в legacy_coding_solver.py. Новый отличается только выбором target_file, использует ограниченную грамматику coding_target.py. Генерация патча, промпт, модель и проверки одинаковы. Реальный SDK, qwen3.8-27b-noreason, temperature=0, max_tokens=700, без reasoning/fallback. Порядок вариантов чередуется.

Бюджет 3000, максимум 8 запросов, per-task 1200. Ожидается 5 API-вызовов: три старых варианта останавливаются без API, контроль вызывает API в обоих вариантах. Пары с отказом до запроса нельзя выдавать за одинаковую оплачиваемую нагрузку или экономию токенов.

Локальные данные: 34 проверки указаний (включая запреты, цитаты, отсутствующие файлы, несколько файлов, публичные/прежние инструкции), старый выбор 18/34, новый 34/34. Все 107 unit-тестов прошли. Подготовка выявила и устранила регрессии слишком строгой грамматики на прежних инструкциях до заморозки. Допустимые выражения ограничены перечисленными шаблонами; произвольная семантика языка не гарантируется.

Эталоны четырёх задач проходят исходные и дополнительные тесты, исходники падают. Дополнительные тесты не передаются модели. Preflight использует эталоны и не является замером качества.

SOLVED учитывается только по сохранённому DONE, проходящим исходным/дополнительным проверкам, неизменности тестов и нецелевых файлов и отсутствию неожиданных файлов. Все запросы, ответы, патчи, тестовые выводы сохраняются. Нет автоматических повторов. Неизвестное usage останавливает новые вызовы; прежние E46/E50 не изменяются.

H05.5 поддерживается на этом пилоте при возврате трёх решений без регрессии контрольной пары и нарушений файлов. Отрицательные контроли проверены локально, не реальными генерациями. Общий challenge 9/19 остаётся историческим.
