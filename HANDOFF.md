## Команда организаторов

    python /app/run_agent.py --tasks-dir /data/tasks

Окружение:

| Переменная | Назначение |
|---|---|
|LLM_BASE_URL|URL прокси API с /v1, передаётся организаторами|
|LLM_API_KEY|Ключ API, передаётся только при запуске|
|BUDGET|Фактический общий бюджет приведённых токенов|
|TOKEN_BUDGET|Альтернатива BUDGET|
|TASKS|Путь к задачам, если нет --tasks-dir|
|OUT|Необязательный JSON-файл итогов или существующая папка; родитель должен быть доступен для записи|

Приоритет бюджета: --budget → BUDGET → TOKEN_BUDGET →100000. По уточнению организаторов100000 — ориентир, фактический бюджет может быть меньше или больше. Не переносить экспериментальные800/2000/3000 или max-api-calls30 в настройки сдачи. Проверены значения0/800/100000/150000 и приоритет CLI над окружением.

## Формат входов и выходов

Каждая задача: /data/tasks/<id>/task.json и файлы рядом либо в workspace/. Ответ сохраняется в корне задачи answer.txt и дополнительно в workspace/answer.txt, если workspace существует. Для coding успешный патч записывается только в выбранный исходный модуль; доступные тесты сохраняются. Неуспешные задачи остаются без ответа. OUT содержит JSON-объект task_id→строковыйответ.

Задачные папки должны быть доступны для записи. Код /app может оставаться неизменяемым; для логов SDK,бюджета и временных вычислений нужен доступный временный каталог. В Linux обычно /tmp.
