## Запуск организаторов

    python /app/run_agent.py --tasks-dir /data/tasks

Эта команда теперь сама выбирает профиль csv-roomy: experimental joins включены; минимумы бюджета search/data/coding — 300/1000/800; multi-CSV cap 600; параллелизм 1. Добавлять --experimental-joins или --profile не требуется. Явный --profile csv-roomy эквивалентен default; --profile validated возвращает прежний проверенный профиль 400/700, --profile legacy — исходные настройки.

LLM_BASE_URL и LLM_API_KEY передаются окружением организаторов. Основной run_agent.py не читает наш neuraldeep.txt. Бюджет задаётся --budget, затем BUDGET, затем TOKEN_BUDGET, иначе 100000. Экспериментальные 2700/3000 и max-api-calls 26 НЕ являются настройками сдачи: их нельзя копировать в Dockerfile. Если организаторы сообщают другой лимит, передать его явно через поддерживаемое окружение/CLI.

answer.txt сохраняется в каждом каталоге задачи после успешного Finalize. При OUT/--out-file дополнительно используется предусмотренный сводный вывод. Проверить именно контракт запуска организаторов: каталог задач доступен для записи; /app read-only; /tmp tmpfs; HOME=/tmp. API только через переданный прокси, без скачиваний при запуске.

## Что проверить при упаковке

Docker отсутствует в этой рабочей среде. Здесь НЕ подтверждены сборка/размер образа, Linux, режим read-only и ограничения ресурсов. Коллега проверяет:

1. docker build с контекстом корня репозитория; зависимости установлены при сборке.
2. Запуск по команде регламента с read-only, /tmp, HOME=/tmp и примонтированными копиями задач; минимум одна задача с API и одна локальная.
3. Реальное появление answer.txt в примонтированных папках, а не только строки SOLVED в журнале.
4. Размер образа < 4 ГБ, время сборки < 1000 s. Отслеживаемые Git-файлы на момент проверки около 8.4 МБ, но это НЕ размер образа. .dockerignore исключает .venv-sdk, experiments, tests, ключи и логи.
5. README, доступ жюри к репозиторию и последний коммит перед закрытием. После синхронизации договориться о заморозке; не смешивать новые изменения решателей с финальной упаковкой.

Не увеличивать параллелизм с 1 до 5 без отдельной проверки. Текущий результат и расход относятся к 1. Временная папка для Python не заменяет изоляцию ОС; процесс должен исполняться внутри контейнера с ограничениями организаторов.
